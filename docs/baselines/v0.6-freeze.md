# v0.6 Baseline Freeze for v0.7 Comparison

The final v0.6 state is preserved by checkpoint `ea1d602c` in the separate `hierarchical-image-representation` repository. It is the comparison baseline for the v0.7 hybrid energy-tree redesign. The freeze contains iterative affinity-threshold agglomeration, explicit best-match and overlap records, measured sparse residual budgets, authenticated owner-scoped analysis access, and bounded sensitivity evidence.

## Reproducible Baseline Commands

```bash
python3 python_engine/test_representation_engine_v3.py
python3 python_engine/test_sensitivity.py
python3 python_engine/test_benchmark_suite.py
pnpm test
pnpm check
pnpm build
```

The existing benchmark suite creates seven deterministic synthetic/bundled fixtures and reports entity counts, relationship counts, reconstruction metrics, heuristic model scores, emitted artifact bytes, and codec-baseline metadata. v0.7 comparisons must run the same fixture and configuration set before adding any external or licensed corpus.

## Comparison Measures

| Dimension | v0.6 baseline record | v0.7 comparison requirement |
|---|---|---|
| Structure | Iterative stage lineage and sparse relationship count | Full merge-tree node/edge count, accepted merge energy, and derived-cut counts |
| Reconstruction | Constant, parametric, residual MSE/PSNR/SSIM | Same modes plus local-coordinate/model and squared-error residual comparisons |
| Storage | Actual emitted run bundle and optional sparse residual bytes | Same actual bytes plus explicit tree/cut contribution fields |
| Cross scale | Hungarian best matches and thresholded overlap links | Same diagnostics plus normalized overlap-matrix coverage |
| Reliability | Engine, benchmark, sensitivity, server, UI, type, and build checks | Existing checks must pass alongside v0.7 invariants |

The baseline does not establish scientific superiority, codec performance, semantic invariance, or external generalization. It is a reproducible engineering control for measuring the effect of the v0.7 architectural change.
